# Opdracht: All D3 states combined
Zorg dat deze opdracht lokaal werkt.

## Inleveren
* Maak een nieuwe branch genaamd **gh-pages** en upload je lokale werk naar deze branch.
* Controleer of jouw werk correct te zien is via de **GitHub Pages URL**. 
* Start een nieuwe **pull request**, selecteer Vincent als **reviewer** en plaats de **GitHub Pages URL** in de comments.
* Klaar! 🥳 (**niet** zelf de Pull Request *mergen*; *mergen* betekent goedkeuring van de reviewer)
